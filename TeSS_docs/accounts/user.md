# User account creation

HEP Training is viewable by everyone, you do not need to register to search or browse for materials.
The materials that HEP Training points to may be restricted-access, but the registry itself is open.
HEP Training uses CERN SSO which allows users to log in using four ways:

1. CERN Account
2. EduGAIN
3. Social Media Account
4. Guest User
